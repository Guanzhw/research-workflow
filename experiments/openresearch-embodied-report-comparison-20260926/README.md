# 探索性报告：两组均加载了 Research Workflow

这两份原始报告来自先前的 OpenResearch Codex 会话。运行记录显示，默认入口和显式调用入口都成功读取了 `research-workflow/SKILL.md`，因此它们只能展示两种入口下的写作结果，不能用作“没有工作流”与“有工作流”的配对比较。

- `default-entry.md`：默认入口的原始报告。
- `with-workflow.md`：显式调用入口的原始报告。

用于用户主观评审的有效配对报告见 [`../openresearch-embodied-direct-comparison-20260926/`](../openresearch-embodied-direct-comparison-20260926/)。
