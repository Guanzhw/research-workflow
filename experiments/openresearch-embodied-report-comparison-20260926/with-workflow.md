# 从 Transformer 到具身智能：机器人学习发展脉络

**范围。** 本报告把具身智能限定为机器人从视觉、语言与自身状态感知环境，规划或学习可执行动作，并利用环境反馈继续行动。重点是 2017—2025 年通用机器人操作。移动导航、自动驾驶、人形运动控制与 2026 年新模型不作全面盘点。Transformer 是序列建模起点，不是具身智能的历史起点。下文的因果关系是根据原论文问题与机制做出的综合解释，不表示后发表方法必然直接继承或取代前者。

## 核心判断

发展并非一条“模型越大越通用”的单线。语言规划解决抽象目标如何落到技能；Transformer 策略把多任务轨迹统一建模；视觉—语言—动作模型（VLA）把语义预训练接到动作；动作块、扩散与 flow 处理连续、精细且有多种正确解的动作；跨机器人数据和世界模型分别处理经验稀缺、行动前预测。这些路线并行且经常组合。

## 技术转折

| 时间与路线 | 此前约束及新机制 | 解决的问题与仍存限制 |
| --- | --- | --- |
| **2017 Transformer** | 循环网络在序列位置间难并行。自注意力直接联系不同位置，降低建模远距离依赖的路径。[原论文](https://www.alphaxiv.org/pdf/1706.03762) | 原论文验证翻译等序列任务；注意力不自带物理动力学、接触反馈或安全性。 |
| **2021—2022 轨迹序列建模** | Decision Transformer 将期望回报、状态、动作组成条件序列；Gato 用同一模型处理文字、图像、游戏和机器人动作。[Decision Transformer](https://arxiv.org/abs/2106.01345)、[Gato](https://arxiv.org/abs/2205.06175) | 统一接口有利于任务共享，但并不证明真实机器人具备广泛可靠的技能。 |
| **2022 语言规划：SayCan** | 语言模型知道合理步骤，却不知道机器人此刻能否做到。SayCan 用技能价值函数约束语言模型提出的步骤。[原论文](https://www.alphaxiv.org/pdf/2204.01691) | 能组织长程任务；仍受已有技能、可供性估计和感知准确性限制。 |
| **2022 端到端策略：RT-1** | 单任务策略难共享演示。RT-1 从视觉、指令和动作数据训练 Transformer；论文报告约 13 万段真实演示及 700 多项任务。[原论文](https://www.alphaxiv.org/pdf/2212.06817) | 促进多任务控制；受具体机器人和数据覆盖范围限制。 |
| **2023 语义迁移：PaLM-E、RT-2** | 机器人数据难覆盖开放词汇与陌生物体。PaLM-E 把视觉和连续状态接入语言模型；RT-2 联合视觉语言预训练和机器人动作训练，把动作表示为可生成符号。[PaLM-E](https://www.alphaxiv.org/pdf/2303.03378)、[RT-2](https://www.alphaxiv.org/pdf/2307.15818) | 改善语义泛化；RT-2 原文指出，物理技能仍受机器人训练数据中的技能分布约束。 |
| **2023 精细动作：ACT、Diffusion Policy** | 逐步模仿易积累误差；同一观察可能对应多条有效轨迹。ACT 一次预测动作块；Diffusion Policy 条件去噪生成连续动作序列，并滚动执行。[ACT](https://www.alphaxiv.org/pdf/2304.13705)、[Diffusion Policy](https://www.alphaxiv.org/pdf/2303.04137) | 更好表达精细、多峰动作；动作块过长削弱即时反馈，迭代生成增加时延。 |
| **2023—2025 数据与融合** | Open X-Embodiment 汇合 22 种机器人的数据并报告正迁移；OpenVLA 发布可获取、可微调的 VLA；π₀ 将视觉语言模型与 flow matching 连续动作生成结合。[Open X-Embodiment](https://www.alphaxiv.org/pdf/2310.08864)、[OpenVLA](https://www.alphaxiv.org/pdf/2406.09246)、[π₀](https://arxiv.org/abs/2410.24164) | 缓解单机体数据不足，但不同机器人动作坐标、视角和动力学不会自动对齐；各论文评测不能直接横比。 |
| **并行路线：世界模型** | 直接预测动作难预先比较长远结果。DreamerV3 在学得的环境模型中想象未来；V-JEPA 2-AC 结合视频预训练与动作条件预测进行图像目标规划。[DreamerV3](https://arxiv.org/abs/2301.04104)、[V-JEPA 2](https://arxiv.org/abs/2506.09985) | 可辅助规划；预测误差会随时域累积，执行中仍需闭环修正。 |

**因果图的读法。** Transformer → 轨迹建模，表示序列工具进入决策学习；机器人演示昂贵 → RT-1 与跨机体数据，表示共享经验的动机；网页语义丰富但机器人技能稀缺 → SayCan、PaLM-E、RT-2，表示不同的语义落地方式；动作多峰且需精度 → ACT、扩散、flow，表示动作输出机制的变化。这些箭头表示针对的瓶颈，不是已证实的直接技术继承。

## 同一任务中的机制差别

假设任务是“把杯子放到托盘”。SayCan 选择“找到、抓取、移动、放下”等已有技能并评估可行性；RT-1/RT-2 根据图像和指令预测动作；ACT/扩散/flow 动作头生成一段连续抓取轨迹，可表示从左侧或右侧接近；世界模型可先预测几种动作后的画面，再执行并重新观察。这是解释机制的构造例子，不是同一基准上的实测比较。[SayCan](https://www.alphaxiv.org/pdf/2204.01691)、[RT-2](https://www.alphaxiv.org/pdf/2307.15818)、[Diffusion Policy](https://www.alphaxiv.org/pdf/2303.04137)、[V-JEPA 2](https://arxiv.org/abs/2506.09985)

## 共性限制与阅读路线

最大的共性问题是：真实机器人数据昂贵且异构；理解指令不等于掌握接触力、遮挡状态和失败恢复；生成时延、反馈频率与安全性需要一起评估。跨论文的任务、机器人和成功率口径不同，不宜作统一排名。[Open X-Embodiment](https://www.alphaxiv.org/pdf/2310.08864)、[RT-2](https://www.alphaxiv.org/pdf/2307.15818)、[ACT](https://www.alphaxiv.org/pdf/2304.13705)

建议按概念依赖读：Transformer 第 3 节 → SayCan 方法 → RT-1 方法与实验 → RT-2 方法 → ACT 或 Diffusion Policy 方法 → Open X-Embodiment 和 V-JEPA 2 方法。依次回答“如何表示序列、如何判断可执行、如何从图像出动作、语义怎样迁移、为何一次生成多步、怎样共享经验或预测未来”。

**理解检查。** 若机器人能正确复述“把透明软袋放进抽屉”，却经常抓空，你会优先补语言数据、真实接触演示、动作表示，还是环境预测？说明主瓶颈及哪种新观察会推翻判断。

**证据边界。** 本文依据原论文的方法与作者报告的实验，未独立复现。资料核查日期：2026-09-26。
